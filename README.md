# Jankifier

My own utils for jank so I can write more jank than C++ \o

Most of the things here will likely be, in the future, not needed by something
as it will be supported officialy from jank, this is just useful for what I want
to build and also to show that jank (like clj) allow us to do whatever we need
to do (even if with some non-pretty macros).
